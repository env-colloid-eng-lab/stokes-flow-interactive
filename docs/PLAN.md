# インタラクティブ教材「テンソルからストークス動力学へ」作業方針

対象資料：『Juliaで学ぶテンソルとストークス動力学』改訂第11版（`Textbook.md` 16章、`Worked_Solutions.md`、Julia実習 `FoundationLab.jl` / `StokesLab.jl` / `TwoSphereLab.jl` / `BridgeLab.jl`、検証記録 v4〜v11、`output/*.csv`）

## 1. ねらい

**「ストークス動力学を使う人が、抵抗行列の各成分がどこから来て、運動とともになぜそう変わるかを説明できるようになる」**

そのために、次の3つを1画面で結び付けて見せる。

1. **式**：その成分を与える式（例：自己項 $6\pi\mu a$、RPY の $c_\parallel,c_\perp$、JO 級数の $f_k(\lambda)$、潤滑 $3\pi\mu a^2/2h$）
2. **数値**：現在の配置で式に値を代入した結果（ヒートマップ・数値表示）
3. **運動**：その行列で解いた粒子の動きと、成分・固有値の時間変化

教科書は「同じ数値が出たことと、使った近似が対象に適していることは別」（読み方と記号）という立場をとっている。教材でもこの立場をとり、各成分にはどのモデルで求めた値かを必ず表示する（RPY／JO級数 K 次／境界条件解法 L 次／潤滑の教材モデル）。

### 2.2 資料に含まれないもの（資料の README・第13.8節・第14章で明記されている）

- JO の全関数（$Y^A, Y^B, X^C, Y^C$、ひずみ・ストレスレット系）と、近接の漸近接続
- 一般3次元の多体SD（Brady–Bossis 型の全ブロック）、壁・周期境界
- 配置依存のブラウンSD時間積分

この結果、**二球の抵抗行列を3Dで厳密に扱えるのは中心線方向（$X^A$）だけ**になる。垂直方向（$Y^A$）や回転との結合は、RPY の逆行列による近似でしか出せない。§7 の決定事項1で扱う。

### 2.3 記号・規約（教材全体で統一する）

教科書の規約をそのまま採用する。授業スライドと異なる点もあるため、各ページの「記号」欄に明記する。

- $L_{ij}=\partial_j u_i$、$E=(L+L^{\mathsf T})/2$、$W=(L-L^{\mathsf T})/2$（授業資料の回転テンソルとは逆符号）
- $\boldsymbol n$：粒子から流体へ向く法線。$\boldsymbol t=\sigma\boldsymbol n$：流体が粒子に及ぼす力
- $\boldsymbol f=-\boldsymbol F^{\mathrm H}$：粒子が流体に及ぼす力。$\boldsymbol U=M\boldsymbol f$、$\boldsymbol f=R\boldsymbol U$
- JO の無次元化：$s=2r/(a_1+a_2)$、$\lambda=a_2/a_1$、式(13.1) のスケール因子つき行列を作ってから逆行列を取る
- 数値例の無次元化：$a=\mu=F_0=1$（$6\pi$ は消さない。時間単位は $\mu a_0^2/F_0$）
- 添字記法を主とし、直接記法を併記する

## 3. 中心となる部品：「抵抗行列ビューア」

二体・多体のページで共通に使うコンポーネント。最初にこれを作り、ほかのページはこれを組み込む形にする。

```
┌──────────────┬──────────────────────────┐
│ 粒子配置       │  R（または M）のヒートマップ        │
│ （2D投影/3D）  │  3N×3N、ブロック境界つき          │
│ ドラッグで移動   │  成分にカーソル → 式と代入値を表示   │
│              │  [M | R | R−R_孤立 | 二体和との差]  │
├──────────────┴──────────────────────────┤
│ 時系列：選んだ成分・固有値・隙間 h の時間変化（時刻スライダで巻き戻し）     │
├─────────────────────────────────────────┤
│ 座標系の切替：実験室系 ⇄ 対の局所系（e方向 / 垂直方向）              │
│   R_αβ = X(r) e eᵀ + Y(r)(I − e eᵀ)                       │
└─────────────────────────────────────────┘
```

「中身がわかる」ために、この部品で次の4点を見せる。

1. **成分が変わる理由は2つある**。粒子間距離 $r$ が変わると $X,Y$ が変わる。対の向き $\boldsymbol e$ が回ると、$X,Y$ が同じでも実験室系の成分が変わる（第1章の基底変換）。座標系の切替で、この2つを分けて見せる。
2. **$M$ は二体の和、$R$ は二体の和ではない**。$R=M^{-1}$ を取ると第三粒子の影響が $R_{12}$ に入る。差分表示「$R$ − 二体和」で多体反射を可視化する（第14.4節の二重計上の話にもつながる）。
3. **固有値・固有ベクトル**。集団運動 $(1,1)$ と相対運動 $(1,-1)$（問9.1）、正定値性、Oseen 行列に負の固有値が現れる配置（問9.2：10球・間隔 $2.01a$）。
4. **成分ごとの出典表示**。どのモデルで求めた値かと、精度（打切り次数・境界残差）を表示する。

| シナリオ | 配置は変わるか | 学べること |

### 5.1 案A・案Bを並べて比べる仕組み

二体の抵抗関数をまとめた「モデル」として、同じ形の関数を返す。

```js
// r：中心間距離、a1, a2：半径。戻り値は JO の規格化に合わせた無次元関数
model.pair(r, a1, a2) → { XA11, XA12, YA11, YA12, YB11, YB12, XC11, XC12, YC11, YC12, source: {...} }
```

| | 案A：教科書の範囲 | 案B：全関数＋近接漸近 |
|---|---|---|
| 軸方向並進 $X^A$ | JO 級数（厳密な漸化式、K次） | 同じ JO 級数＋潤滑漸近式との接続 |
| 垂直並進 $Y^A$ | 並進 RPY 移動度の逆行列（下の注意を参照） | JO 1984 の漸化式による級数＋漸近式 |
| 並進回転結合 $Y^B$、回転 $X^C, Y^C$ | 扱わない（必要なら回転 RPY ブロックを追加する。教科書外なので別にテストする） | 同上 |
| 近接 | 法線潤滑の教材モデル（階数1、$h_c$ で打ち切り） | 各関数の特異項（$1/h$、$\ln(1/h)$）を分離した漸近式 |
| 多体 | $R=M_{\mathrm{RPY}}^{-1}$（＋教材潤滑） | $R=(M^\infty)^{-1}+\sum(R^{2B}-R^{2B,\infty})$（式14.2） |

**同じ条件どうしで比べる**ことに注意する。並進 RPY は力だけを与えてトルクはゼロ（自由回転）とした移動度なので、その逆行列は「回転を固定した」$Y^A$ とは別の量である。案Bの力・トルク抵抗から回転自由度を Schur 補行列で消去し（§14.3 と同じ操作）、トルクゼロの並進抵抗にしてから案Aと比べる。回転を固定した場合とトルクゼロの場合の違い（§13.8）自体も、比較画面で見せる。

比較の見せ方：

- **同じ配置で並べる**：ヒートマップを左右に並べ、差 $R_B-R_A$ も表示する
- **距離依存の比較**：$X^A, Y^A, \ldots$ を $r$ の関数として重ねて描く。両対数の差 $|R_B-R_A|$ から**何次から違い始めるか**を読む（例：自己抵抗はストレスレットの寄与で $r^{-4}$ から変わる。§13.3、`BridgeLab.jl`）
- **同じ初期条件で並べる**：軌道を重ねて描き、隙間 $h(t)$ と成分の時間変化を比較する。案Aで「接触しない」（$h\propto e^{-Kt}$）のは案Bと同じか、どこが違うかを見る
- **成分の出典表示**：どちらのモデルでも、各成分を求めた式と打切り次数を表示する

案Bは教科書の外に出るため、検証を別に立てる。

- JO（1984）・Jeffrey（1992）の漸化式から係数を生成し、論文の表の値と照合する
- 軸方向 $X^A$ は案Aの JO 級数と、境界条件解法の結果に一致すること
- 遠方で案Aと一致し、差が予想した次数（$r^{-4}$ など）で現れること
- 対称性と正定値性（近接まで）、近接では漸近式と級数が滑らかにつながること
- 漸近式は Townsend（2018）の再導出とも照合する

注意：論文 PDF は、こちらの作業環境から取得できない可能性がある。取得できない場合は、論文（または必要な式と表の該当ページ）を共有してもらう必要がある。

### 5.2 three.js の利用（決定：使う。リスクと対策）

| リスク | 内容 | 対策 |
|---|---|---|
| WebGL が使えない環境 | 学校の共用PC・仮想デスクトップ・古いタブレットで WebGL が無効、または遅い | **全ての学習内容を 2D 表示だけで完結させ**、3D は追加の表示とする。WebGL がなければ自動で 2D に切り替える |
| 版の非互換 | three.js は約1か月ごとに版が上がり、API の変更・削除が多い（OrbitControls などは addons 側） | 版を固定して `vendor/` に同梱する。three.js を直接呼ぶのは `scene3d.js` だけにする |
| CDN 依存 | CDN 障害や学内ネットワークの制限で読み込めない | CDN を使わず同梱する（three.module.min.js 約0.34 MB＋core 約0.38 MB） |
| 読み取りにくさ | 透視投影では奥行きを読み違えやすく、行列の添字と空間の向きを対応させにくい | 既定は正射影。座標軸 $x,y,z$ を行列の添字と同じ色で表示し、軸方向から見る視点ボタンを付ける |
| テストしにくい | WebGL 描画は `node --test` で検証できない | 物理計算は描画から切り離して Node でテストする。描画は Playwright（ヘッドレス Chromium）の画面確認で補う |
| 性能 | 粒子・流線が多いと低性能端末で遅い | 粒子数は数十まで。InstancedMesh を使い、流線は 2D 断面で描く |

### 5.3 トピックのつながり

講義回との対応は示さず、**トピック間の依存関係**を明示する。

- `src/topics.js` に「この結果 → どこで使うか」の対応をデータとして持つ。例：
  - 基底変換（p1）→ 対の局所系 $X,Y$ への分解（p8）
  - 散逸の正値性（p4）→ 移動度・抵抗の正定値性（p8）→ 雑音の共分散（p12）
  - 球面積分の $6\pi\mu a,\ 8\pi\mu a^3,\ \tfrac{20\pi}{3}\mu a^3$（p6）→ 自己ブロック（p8）→ 11成分（p11）
  - Faxén 則（p7）→ RPY（p8）→ 案Aの遠方相互作用（p8–10）
  - ストレスレット（p6）→ JO 自己抵抗の $r^{-4}$ 項（p9）
- 各ページの冒頭に「このページで使う結果」、末尾に「この結果を使う先」を表示する
- 地図ページで全体を有向グラフとして表示する

### 5.4 公開とオフライン利用

- 基本は GitHub Pages で公開する。
- オフライン用の選択肢も用意する。ただし ES Modules は `file://` で直接開くとブラウザに拒否されるので、ZIP を展開して `python3 -m http.server` を1行実行する手順を案内する。必要になれば、ダブルクリックで開ける単一ファイル版を生成するスクリプトを追加する（任意のビルド手順で、通常の公開には使わない）。
- **リポジトリは公開設定である**。コミットした内容はすぐに誰でも見られる。また Pages を有効にすると、サイトもすぐに公開される。

## 9. 教材に入れる「つまずき」の例（教科書から抽出）

各ページの「よくある誤り」欄で、誤った操作の結果も見せる。

- 潤滑の $F$ を $2F$ にしてしまう（相対速度と一球の速度の取り違え、§10.1）
- JO の無次元関数をスケール因子なしで逆行列にする（§13.2）
- `sqrt.(M)`（要素ごとの平方根）で雑音を作る → 共分散が合わない（§15.2）
- 熱ドリフト $k_BT\,\partial M$ を省く → 平衡分布が $e^{-V/k_BT}/M$ にずれる（§15.4）
- 打ち切った遠方展開の行列が正定値だと思い込む（§9.3、`reflected_mobility` の注記）
- 数値の非対称を `Symmetric` で隠す（§9.4）
- 回転テンソルの符号が授業と本文で逆（Lecture_mapping）
- 一つの二球対で正しくても、多球の行列全体が正しいとは限らない（問9.2）
